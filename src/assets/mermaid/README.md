# mermaid 测试素材 (260917-01)

手动验收用静态素材 (与 `src/assets/example/` 定位一致, 不被代码引用)。

## 使用方法

1. 启动 `pnpm dev` 后打开编辑器页 `http://127.0.0.1:7364/md`。
2. 把任意 `.md` 文件的全文粘贴进编辑器, 预览区应渲染出对应图表。
3. 验收点:
   - 图表渲染成功 (无 error 降级源码);
   - 切换明暗主题, 图表配色跟随重渲染;
   - 窄窗口下超宽图表可横向滚动;
   - `error.md` 应展示错误信息与源码降级;
   - 复制 (工具栏复制按钮 / 微信预览模式) 后图表以图片形式进入剪贴板。

## 文件清单

| 文件 | 覆盖图型 |
| --- | --- |
| `flowchart.md` | 流程图 (任务文件示例 + 子图 + 中文标签) |
| `sequence.md` | 时序图 (循环 / 激活 / 注释) |
| `class.md` | 类图 (继承 / 组合 / 关系基数) |
| `state.md` | 状态图 (状态机 v2 语法) |
| `er.md` | 实体关系图 |
| `gantt.md` | 甘特图 (任务 / 里程碑 / 排除时段) |
| `pie.md` | 饼图 |
| `journey.md` | 用户旅程图 |
| `mindmap.md` | 思维导图 |
| `timeline.md` | 时间线 |
| `gitgraph.md` | Git 分支图 |
| `others.md` | 桑基图 / 象限图 / XY 图表 (较新图型; 注意 sankey/xychart 的节点名与轴标签仅支持 ASCII, 为 mermaid 语法限制) |
| `error.md` | 非法语法 (错误降级验收) |
| `all-in-one.md` | 全部图型汇总 (长文档性能与滚动验收) |
